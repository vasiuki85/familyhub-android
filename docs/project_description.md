# FamilyHub - Описание проекта и Roadmap

## 📱 Описание проекта

**FamilyHub** — это Android-приложение для организации семейной жизни. Оно помогает семьям распределять задачи, вести совместный список покупок, отслеживать события и мотивировать членов семьи через систему баллов.

### Целевая аудитория
- Семьи с детьми (от дошкольного возраста)
- Родители, которые хотят научить детей ответственности
- Семьи, где нужно распределять домашние обязанности

### Решаемые проблемы
1. **Забывчивость** — задачи не выполняются вовремя, потому что никто не помнит, кто за что отвечает
2. **Несправедливость** — постоянные конфликты "я делаю всё один" без объективного учёта вклада
3. **Разобщённость** — покупки и события забываются, потому что нет единого места для информации

## 🎯 Текущее состояние (MVP v0)

### Реализованная функциональность

#### ✅ Экран "Дом" (Home)
- Просмотр задач текущего пользователя на сегодня
- Отображение ближайших событий (до 2 штук)
- Показ баллов за текущую неделю
- Выбор текущего пользователя через выпадающий список
- Создание новых событий через FAB

#### ✅ Экран "Задачи" (Tasks)
- Вкладки "Мои" и "Все" задачи
- Список задач с детальной информацией:
  - Статус (выполнено/невыполнено)
  - Кому назначено
  - Кто создал
  - Дедлайн
  - Правило повторения
- Создание новых задач с указанием:
  - Названия и описания
  - Дедлайна
  - Правила повторения (нет/ежедневно/еженедельно)
  - Назначенного исполнителя
- Переключение статуса задачи (выполнено ↔ невыполнено)
- Автоматическое начисление баллов при выполнении задачи
- Автоматическое создание повторяющихся задач

#### ✅ Экран "Покупки" (Shopping)
- Список покупок с возможностью отметить "куплено"
- Информация о том, кто добавил товар
- Создание новых позиций в списке покупок
- Отметка товаров как купленных

#### ✅ Экран "Рейтинг" (Rating)
- Рейтинг всех членов семьи за текущую неделю
- Сортировка по убыванию баллов
- Информационное сообщение о системе баллов

#### ✅ Бизнес-логика
- **Система баллов**: +1 балл за каждую выполненную задачу
- **Повторяющиеся задачи**: при выполнении создаётся новая задача на следующий день/неделю
- **Недельный цикл**: баллы считаются с понедельника по воскресенье
- **Текущий пользователь**: можно переключаться между членами семьи

#### ✅ Технические компоненты
- **Архитектура**: Clean Architecture (Data → Domain → UI)
- **Локальное хранение**: Room Database + DataStore Preferences
- **Реактивность**: Kotlin Flow для автоматического обновления UI
- **Dependency Injection**: Hilt
- **UI**: Jetpack Compose + Material 3
- **Навигация**: Navigation Compose
- **Обработка ошибок**: во всех ViewModels с отображением в UI

#### ✅ Инициализация
- Автоматическое создание тестовых членов семьи при первом запуске:
  - Папа (синий цвет)
  - Мама (розовый цвет)
  - Сын (зелёный цвет)
  - Дочь (оранжевый цвет)

### Технический стек

#### Языки и фреймворки
- **Kotlin** 1.9.20
- **Jetpack Compose** (Material 3)
- **Android SDK**: Min 24, Target 34, Compile 34

#### Библиотеки
- **Hilt** 2.48 — Dependency Injection
- **Room** 2.6.1 — локальная база данных
- **DataStore Preferences** 1.0.0 — хранение настроек
- **Navigation Compose** 2.7.6 — навигация
- **ViewModel + StateFlow** — управление состоянием UI
- **Kotlin Coroutines** 1.7.3 — асинхронность
- **Kotlin Serialization** 1.6.0

#### Архитектура
```
app/
├── data/              # Слой данных
│   ├── local/         # Room Entities, DAOs
│   ├── datastore/     # DataStore для настроек
│   └── repository/    # Репозитории (абстракция над источниками данных)
├── domain/            # Бизнес-логика
│   ├── model/         # Domain модели (чистые data class)
│   ├── usecase/        # Use Cases (бизнес-операции)
│   └── utils/          # Утилиты домена
├── ui/                 # UI слой
│   ├── screens/        # Экраны приложения
│   ├── components/     # Переиспользуемые UI компоненты
│   ├── navigation/      # Навигация
│   └── theme/          # Тема приложения
└── di/                 # Hilt модули
```

## 📝 Примечания

### Что НЕ входит в MVP
- Синхронизация между устройствами (только локальное хранение)
- Аутентификация пользователей (все видят всё)
- Приватность данных (все члены семьи видят все данные)
- Удаление/редактирование после создания (базовая версия)

### Принципы разработки
1. **Простота прежде всего** — MVP должен работать сразу после установки
2. **Семейный фокус** — приложение для семьи, не для корпораций
3. **Мотивация через геймификацию** — баллы и награды должны мотивировать
4. **Честность и прозрачность** — все данные видны всем для доверия
