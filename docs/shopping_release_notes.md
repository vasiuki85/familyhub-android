# Релизные подсказки: обновлённый список покупок

## Новое
- История действий синхронизируется между устройствами через Firestore, включая отметки и изменения участников.
- Локальные уведомления на устройстве при изменениях от других участников (после sync).
- Диалог добавления товаров поддерживает автозаполнение, категории, единицы и пакетный ввод.

## Что сообщить пользователям
1. **Совместная работа.** Приглашайте всю семью, чтобы видеть кто и когда купил товар.
2. **Фильтры и категории.** Используйте фильтры «Не куплено» и цветовые категории для быстрого поиска.
3. **История изменений.** Открывайте историю, чтобы проверить кто перенёс или удалил позицию.
4. **Синхронизация.** Для актуальных списков на всех телефонах включите облачную синхронизацию и периодически открывайте приложение.

## Требования
- Включённая синхронизация семьи (Firestore).
- Разрешение на уведомления при первом запуске раздела «Покупки».

## Известные ограничения
- Push в фоне на закрытое приложение **не** используется (нет Firebase Blaze / Cloud Functions).
- Уведомления о чужих действиях приходят, когда приложение открыто или после фонового sync.
- История ограничена последними 90 днями; экспорт сохраняет полные записи.
