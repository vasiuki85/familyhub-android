# Firebase Firestore Security Rules

## Установка правил

1. Скопируйте содержимое файла `firestore.rules`
2. Откройте Firebase Console → Firestore Database → Rules
3. Вставьте правила и нажмите "Publish"

## Основные правила

### Документ семьи (`/families/{familyId}`)
- **Чтение/запись**: Любой авторизованный пользователь может читать и создавать/обновлять документ семьи
- Это необходимо для создания новой семьи

### Участники (`/families/{familyId}/members/{memberId}`)

#### Создание себя как ADMIN
- Разрешено если:
  - Пользователь создаёт свою запись (`request.auth.uid == memberId`)
  - Роль = `ADMIN`
  - Записи ещё нет в БД (первое создание семьи)

#### Создание/обновление заявки (PENDING)
- Разрешено если:
  - Пользователь создаёт/обновляет свою запись
  - Роль = `PENDING`
  - Записи нет ИЛИ текущая роль = `PENDING`

#### Обновление своей записи
- Разрешено обновление имени, аватара и т.д.
- **Запрещено** изменение роли (роль может менять только админ)

#### Админские права
- Админ может создавать/обновлять/удалять любых участников

### Остальные коллекции
- Все остальные коллекции (tasks, shopping, events и т.д.) доступны для чтения/записи авторизованным пользователям

## Отладка

Если возникают проблемы с правами доступа:

1. Проверьте, что пользователь авторизован (`request.auth != null`)
2. Проверьте логи в Firebase Console → Firestore → Usage
3. Используйте Firebase Emulator для локальной отладки правил

## Важные замечания

- При batch операциях правила проверяются для каждой операции отдельно
- `exists()` проверяет текущее состояние БД (до выполнения batch)
- При создании семьи документ может создаваться одновременно с member в одном batch
